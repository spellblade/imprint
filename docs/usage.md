# Usage

## Playground (this site)

1. Open Playground from the landing cards.
2. Pick a sample site.
3. Fill from vault (heuristic) or Fill with AI.
4. Answer custom-field asks; check save-to-vault.
5. Save the form; reopen from Library.

Maya Ellison is preloaded. Data stays in this browser origin.

## Extension (real pages)

1. Load unpacked from the ZIP (`imprint/` folder containing `manifest.json`).
2. Open a real form.
3. Popup → Scan → Fill.
4. Unknown fields prompt once. Save to vault to reuse.
5. Save remembers the page.

Vault starts empty in the extension. Edit vault in the popup before the first real fill.

## Never filled

Passwords, card numbers, CVC, SSN-like fields, legal/terms checkboxes.
